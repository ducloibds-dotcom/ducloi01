Khối Đồng hồ

            
Chèn đồng hồ LED chạy realtime vào tin đăng.

          

        

        

          
Xem trước code

          

            
<div class="kenyo-clock kenyo-led">
    <div class="time" id="kenyoTime">.</div>
</div>

          

        

        

          ⚡ Khối này không cần điền gì thêm — bấm "Tạo code" để lấy đoạn HTML chèn vào CMS.
        

      


      
      

        

          
🖼️

          

            
Khối Ảnh

            
Nhiều ảnh, mỗi ảnh có caption/alt/title riêng. Viết caption ảnh 1 → bấm "✓ Tạm ổn" để đồng bộ caption/alt/title cho tất cả ảnh (tự thêm - Ảnh 1, Ảnh 2... ở cuối), vẫn sửa lại được từng ảnh sau đó. Bỏ tick ✔ ở đầu ảnh để tạm loại khỏi code lúc đăng mà không cần xóa.

          

        

        

          
          

          
        

        

          ⚡ Dấu "/" dư ở đầu link ảnh sẽ tự động bị xóa khi tạo code.
        

      


      
      

        

          
📕

          

            
Khối Ảnh sổ

            
Nút "Nhấn xem hình ảnh sổ" + gallery ẩn hiện khi bấm. Viết caption ảnh 1 → bấm "✓ Tạm ổn" để đồng bộ caption/alt/title cho tất cả ảnh (tự thêm - Ảnh 1, Ảnh 2... ở cuối). Bỏ tick ✔ để tạm loại ảnh khỏi code mà không cần xóa.

          

        

        

          
          

            
            
          

        

        

          
          
          
          
        

        

          
          

          
        

        

          ⚡ Dấu "/" dư ở đầu link ảnh sẽ tự động bị xóa khi tạo code.
        

      


      
      

        

          
▶️

          

            
Video +

            
SEO video YouTube Shorts: tiêu đề H3 + khung nhúng + caption + schema VideoObject. Bỏ tick ✔ để tạm loại video khỏi code mà không cần xóa.

          

        

        

          
          
        

        

          
          

          
        

        

          ⚡ Dán nhiều link (mỗi dòng 1 link) vào ô link → tự tách thành nhiều video. Ảnh bìa tự lấy từ YouTube. SEO: mỗi video 1 tiêu đề riêng có từ khóa + khu vực, mô tả 1–2 câu.
